Edy developer documentation

Edy is an embeddable workbench for visual-editor extensions. It supplies isolated instances, UI surfaces, controls and preview messaging; your application and trusted extensions own document formats, persistence and project-specific editing.

Get started

  • Installation and integration: run the examples and mount an editor.
  • Extensions: register views, commands, menus and documents.
  • Live preview: display extension-owned content alongside an editor.
  • API reference: configuration and exported controls.
  • Development and deployment: tests, builds and HTML help.

The standalone example demonstrates a sample extension. Its sample document can be edited while Split preview is open. Host integration demonstrates two independent instances.
